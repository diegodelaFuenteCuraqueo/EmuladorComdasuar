Emulador COMDASUAR — Test manual

Parser AMS, secuencias, bancos, heurísticos, reproducción WebAudio, exportación MIDI y partitura VexFlow (pentagrama de piano, un compás por secuencia). Cargado vía npm run dev (http://localhost:3000); con file:// el bundle comdasuar.js debe estar junto a este archivo y no se muestran las partituras de ejemplo. La partitura VexFlow se carga desde CDN y requiere conexión a internet.

5. Exportación MIDI

  
El banco actual se exporta como un ZIP con un archivo .mid por secuencia
  (etiquetados banco_secuencia, p. ej. 0_0.mid). También se mantiene
  la opción de un único SMF formato 1 con una pista por secuencia (PPQ 480).

  

    
    
    
  






  
6. Partitura VexFlow

  
La secuencia actual se dibuja como partitura de piano (pentagrama doble, agudos
  en clave de sol y graves en clave de fa, repartidos por el Do central). Toda la
  secuencia va en un solo compás, sin líneas divisorias ni armadura. VexFlow se
  carga desde CDN; sin red esta sección queda deshabilitada.
